« Même code » ? Non. Route partagée → rendu par jeu

Partagé = la plomberie (l'URL + récupérer le match + un header commun). Le corps de la page est un composant différent par jeu, aussi custom que tu veux.

1 · Comment UNE route donne des pages différentes
Aiguillage par jeu (le routeur lit le segment [game])
/match/[game]/[id]  →  lit [game]  →  choisit le composant :
├─ valorant → <ValorantMatch/>  scoreboard ACS/ADR/KAST
├─ lol     → <LolMatch/>  KDA + draft
├─ cod     → <CodMatch/>  maps + score
└─ … 1 composant = 1 jeu
